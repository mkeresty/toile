# Toile

Interfaces, drawn into being. Toile is a source-owned React component system where editorial illustration, semantic HTML, and restrained motion become one object.

## Development

```bash
npm install
npm run dev
```

Build the showcase with `npm run build`. Registry items are declared in `registry.json` and can be installed through the current shadcn GitHub registry flow as `mkeresty/toile/<item>`.

## Principles

- Semantic HTML remains the interaction layer.
- Artwork is composed in meaningful layers and anchors.
- Motion communicates cause, depth, and state.
- Reduced-motion users receive an intentionally static edition.
- Every installed file belongs to the adopting team.

See `docs/` for architecture, art direction, motion, and quality standards.
