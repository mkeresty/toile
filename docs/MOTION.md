# Motion

Four systems remain separate: intro construction, ambient life, scroll depth, and interaction response. CSS or WAAPI owns inexpensive continuous motion; React state coordinates component-to-artwork causality. Architecture stays nearly still. Leaves move more than limbs, and event-based birds should not expose short loops.

The first visit draws structural groups before texture and copy, without blocking interaction. Route changes do not replay the full sequence. `prefers-reduced-motion` reveals the complete edition immediately, removes parallax and ambient loops, and preserves short state transitions where necessary.
