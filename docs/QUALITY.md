# Quality bar

Every component is reviewed for hover, focus-visible, active, disabled, loading, error, overflow, touch, keyboard, zoom, and reduced-motion behavior. Decorative art is hidden from assistive technology; meaningful art receives concise alternatives.

Release gates include production build, registry validation and install smoke tests, interaction and accessibility tests, first-load and open-state visual regression, three responsive widths, and practical Chromium/WebKit/Firefox checks. Continuous motion must avoid React rerenders and layout-triggering scroll handlers. Dense texture is revealed by groups or masks rather than thousands of independent animations.
